# One Star, Written in Sap

A one-line houseplant 1-star review of its human owner, written in the plant's own voice: a houseplant that only gets dragged into the sunlight when guests are coming, and has learned to associate being loved with the sound of the doorbell.

## Run it

```sh
node main.ts
```

This writes the review to `/output/entry.txt`.
